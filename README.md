BFit: A Fitness Website

Overview

BFit is a serverless web application designed to promote a healthy lifestyle and reduce health risks in a fun and economical way. It provides users with various fitness-related features, including workout plans, calorie tracking, diet planning, and BMI calculation.

Problem Statement

Regular exercise and physical activity contribute significantly to body fitness and psychological health. However, more than 70% of the world’s population is not physically active enough to reap these benefits. Many adults suffer from non-communicable diseases such as diabetes, cancer, and heart disease due to physical inactivity.

BFit aims to bridge this gap by encouraging users to adopt a healthier lifestyle through a digital fitness solution.

Goals of the Project

Promote a healthy lifestyle and reduce health risks.

Provide access to fitness and wellness programs.

Offer versatile exercises that can be performed anywhere, with or without equipment.

Features

Fitness Advice: Personalized exercise recommendations.

Calorie Tracking: Monitor daily calorie intake.

Diet Planning: Structured meal plans for healthy eating.

BMI Calculator: Calculate Body Mass Index.

Animated Workout Videos: Step-by-step exercise demonstrations.

Support for Multiple Environments: Home workouts, gym exercises, and yoga.

Technologies Used

BFit is developed using Bootstrap, a front-end framework that provides:

Responsive Designs for mobile and desktop.

Pre-styled Components for easy UI development.

Browser Compatibility across various web browsers.

Integrated JavaScript Plugins for enhanced interactivity.

Setup & Installation

Clone the Repository

git clone https://github.com/Indravaraj123/BFit.git

Navigate to the Project Directory

cd BFit

Open the project in a browser

If using VS Code, install the Live Server extension.

Open index.html and click Open with Live Server.
